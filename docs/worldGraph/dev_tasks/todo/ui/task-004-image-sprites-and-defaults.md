# task-004: Image sprites (URL display + default per-type sprites)

**Status**: Todo

## Goal

Round out image handling on nodes:

1. Display an image on a node as a sprite directly from a URL (already partly
   working: uploads become data URLs and render as circular sprites)
2. Default sprites for node types so new nodes get a recognizable icon
   (locations, persons, concepts, items) instead of only a colored circle with
   a letter

## Design notes

- Circular sprite rendering exists: `_createCircularSpriteMap(imageUrl, callback)`
  in visualization.js; default SVG letter sprites are generated by
  `generateDefaultSprite(type)` in storage.js. Extend the generator with simple
  per-type glyphs or emoji-based textures.
- Remote URLs need CORS-safe texture loading and an error fallback to the
  default sprite.

## Acceptance criteria

- [ ] Node renders sprite from remote image URL
- [ ] Fallback to default sprite on load error
- [ ] Distinct default sprite per node type
- [ ] Existing upload flow unchanged
